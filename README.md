# Stolice Europy

## Opis Repozytorium
Jest to repozytorium odpowiedzialne za projekt związany ze stworzeniem strony o Stolicach Europy.

## Opis projektu
Jest to projekt mający na celu stworzyć stronę internetową o tematyce Stolic Europy.
Opisywana będzie ich historia jak i wykorzystywane będą zdjęcia atrakcji turystycznych, czy miejsc wartych odwiedzenia w danej stolicy.

## Wykorzystywane technologie
Wykorzystynywanymi technologiami będą HTML i CSS.
